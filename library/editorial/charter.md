# 编辑方针（浓缩版）

> 给未来的自己和新对话看的工作底稿。完整需求见项目总 Prompt；这里只保留做决定时真正要用的规则。

## 一句话

读者因为内容有意思而读完，法语在途中自然发生。

## 重心调整（2026-10-14，读者反馈）

**重点是"趣味学单词"，不是阅读训练。** 读者另有阅读材料。

- 每篇文章的核心产出是**词**：一个词、一组词，或一条能一次解锁很多词的规律（拼写对应、构词、词族）。
- 阅读题、TCF 式练习只在对记词真有帮助时出现，不作为常规内容；不再写以"读懂一篇文件"为目标的文章。
- 优先选题：英语假朋友、英法拼写/构词对应、有可靠来历的词族、魁北克生活词、一词多义带来的有趣发现。
- 法语例句保持短而真实，服务于记词，不追求篇幅。

## 写作

- 从一个疑问、一个误解、一句真实法语、一个现象开始。不从"今天我们学习……"开始。
- 不向读者展示后台结构。没有固定栏目，没有"TCF 价值""一句话总结"之类的标签。
- 一个道理讲明白就往前走。不要用中、英、法各讲一遍。
- 长短随内容。两三段能讲透就两三段。
- 标题要指向一个真问题，不用"99% 的人都不知道"。
- 英语是工具，不是任务。对不上就不对。
- 词源只写可靠的、真能帮助理解的。宁缺毋滥。

## 语言比例（随等级变化）

| 等级 | 叙述 | 法语 |
|---|---|---|
| A1–A2 | 中文为主，英语点拨 | 短句、标识、对话，基本都给意思 |
| B1 | 中文叙述，法语例句不逐句翻译 | 开始出现成段法语 |
| B2 | 中文只做引导和点评 | 主体是法语段落，不配翻译 |
| C1 | 极少中文 | 长文、论证、语体差异 |

## 等级分布（整个库的参考，不是每批的硬指标）

A1–A2 ≈ 10%｜B1 ≈ 20%｜B2 ≈ 55%｜B2+–C1 ≈ 15%

## TCF 阅读能力（在文章里自然训练，不贴标签）

主旨、细节定位、上下文词义、指代、逻辑关系（转折/因果/让步/条件/补充）、作者态度与目的、隐含推断、事实与观点、长文整合。
只有文章本身适合时才加练习题；练习题全部原创，不冒充官方真题。
涉及 TCF Canada 考试结构、题数、时长时，必须先查官方（France Éducation international / IRCC）当前信息。

## 加拿大与魁北克

- 区分：通用标准法语 / 魁北克常用 / 法国常用 / 其他地区。
- 法律、公共服务、政策：只写核查过的，在 `sources.md` 记出处和日期。
- 不为了"加拿大特色"硬塞文化内容。

## 词汇

- 不解释每个词；只解释值得解释的（假朋友、关键区别、能带出一组词的规律、决定文意的连接词、加拿大生活高频表达、能引出知识发现的词）。
- 讲过的词不从零再讲；只在出现新用法时补充。
- 区分：接触过 / 讲解过 / 复现过 / 掌握 / 易错。台账只管重点目标词。

## 核查

- 语言示例可以原创，现实世界的事实不能编。
- 查不到可靠来源的，正文里标【待核查】，进 PDF 之前必须清掉。

## 文件命名

- 选题卡：`C01`…；对应文章：`A001`…（第一批卡号与文章号一一对应，之后批次继续递增）。
- 文章文件：`articles/A001-actuellement.md`。文件头部用 HTML 注释写编辑元数据，读者看不到。
