# Annexe A · Tableaux de conjugaison <small>Verb tables · 动词变位表</small>

The 24 most useful verbs in the 8 tenses you need for B2. Present, passé composé, imparfait, futur, conditionnel, subjonctif, plus the imperative and participles. 24 个最常用动词的 B2 必备时态。

:::tip How to read · 怎么看
Each table gives **je · tu · il · nous · vous · ils**. Compound tenses (plus-que-parfait, futur antérieur, conditionnel passé, subjonctif passé) are formed with the auxiliary shown in the passé composé column + the participle.
:::

## Résumé de la formation des temps · How each tense is built · 时态构成速查

| Tense | Formation | Example |
|---|---|---|
| Présent | stem + -e/-es/-e/-ons/-ez/-ent (-er) or -s/-s/-t… | je parle, je finis |
| Passé composé | avoir/être (présent) + p.p. | j'ai parlé, je suis allé |
| Imparfait | *nous* stem + -ais, -ais, -ait, -ions, -iez, -aient | je parlais |
| Plus-que-parfait | avoir/être (imparfait) + p.p. | j'avais parlé |
| Futur simple | infinitive (stem) + -ai, -as, -a, -ons, -ez, -ont | je parlerai |
| Futur antérieur | avoir/être (futur) + p.p. | j'aurai parlé |
| Conditionnel présent | future stem + imparfait endings | je parlerais |
| Conditionnel passé | avoir/être (conditionnel) + p.p. | j'aurais parlé |
| Subjonctif présent | *ils* stem + -e, -es, -e, -ions, -iez, -ent | que je parle |
| Subjonctif passé | avoir/être (subjonctif) + p.p. | que j'aie parlé |
| Impératif | présent of tu/nous/vous, no subject (-er: no -s) | parle, parlons, parlez |
| Gérondif | en + *nous* stem + -ant | en parlant |
| Infinitif passé | avoir/être + p.p. | après avoir parlé |
