# The Spanish World · 西班牙语世界

Spanish ⇄ Simplified Chinese edition of *The French World* (`../french-world/`): Latin American (Mexican) Spanish with notes for Spain, set in Ciudad de México and Madrid. Same format, layout and build.

📘 [`The_Spanish_World.pdf`](The_Spanish_World.pdf) — **current status: front matter, opening triptych and Volume I (A1, N.º 1–3)**, 173 pages, 41 pieces, 388 vocabulary entries, 91 expressions. N.º 4–13 and the DELE/SIELE section are not written yet (plan in [`docs/PLAN.md`](docs/PLAN.md)).

Build: `npm install && bash tools/make.sh` (see `../french-world/README.md`).
